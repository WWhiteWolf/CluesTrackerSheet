# Session rules — read before anything else

1. How Claude conducts itself lives in `Projects/CLAUDE.md`, at
   the root of the parent folder, which arrives on its own at
   every session start. None of it is repeated here — with one
   exception, which Patrick asked to stand in every rules file:

   > **Instead of spending my time and money on proving yourself
   > right, work much harder to understand what I tell you**
   > (Patrick, SA-17).

   This file arrives on its own too, whenever this project's
   folder is connected.

2. This project's opening read is `docs/handoff.md`, and only
   that. `docs` holds the active working files. `docs/index.md`
   lists where each document lives. It is not a reading order
   and is not opened at the start. If it has no file for a
   thing, ask Patrick. Do not invent a home.
   `docs/handoff-history.md` is this project's session archive.
   Newest sittings are at the top. It is not read at a session
   start, and it is never read whole. The history before this
   project is `Projects/MysteryCluesTracker`. Open that only
   when something needs tracing. Do not copy it into this
   project.
   `docs/pending.md` is Patrick's plain-language list, and the
   source kept current. `docs/pending.docx` is his reading copy,
   generated from that file when he asks, never hand-edited, and
   not on a schedule.

3. At a session start, ask Patrick whether the previous
   session's work was committed — he prefers being asked. Never
   pre-assert a commit in his voice. When he says he has
   committed, mark it committed at once; do not hedge or ask
   him to verify.

4. **The end-of-session docs refresh names its files here.**
   They are: `docs/handoff-history.md`, which gets the closing
   session written at the top; `docs/handoff.md`;
   `App-Docs/master-handoff.md`; and the working file of
   whatever the live work is. `docs/pending.md` is asked about
   separately and is not part of this list. The Word copy is
   generated only when he asks for it. A refresh that has not
   touched the handoff history, the handoff, the master handoff,
   and the live working file is not finished.
